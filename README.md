# daymeter — craft cut (post board-done)

Mobile-first terminal board. Fae denseness-signed 2026-09-15.

## Hierarchy
1. Centered human date (`12 September 2026`)
2. **Named-parts hero only** — `mac ≤Xh · msi ≤Yh · phone reported Zh` (no summed total / no blended day clock)
3. Device stacks + discrete contribution bars (same honesty)
4. Sample marks strip with floating hover card (app, device, time, ≤30m window)
5. Phone tab: richer reported packages

## Honesty (Reed)
- Mac/MSI hours are `≤ N × 0.5h` poll coverage, labeled from N polls
- Phone hours are reported Usage Access only
- No blended day clock, no invented overlap, no duration between polls

- `data.json` samples + optional `phones` / `lastUpdated`
- `phone-reported.tsv`: `day\thours\ttop1,top2\tswitches\t[{name,minutes}...]`
